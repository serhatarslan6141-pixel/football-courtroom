# Football Courtroom frontend

The React/Vite interface for match replay and the five-stage courtroom.
See the [project README](../README.md) for setup, the cached demo and AI behavior.

From this directory: `npm ci`, `npm run dev`, `npm test`, `npm run lint`,
and `npm run build`. Vite forwards `/api` to the local backend on port 8000.
Set `VITE_API_BASE_URL` to use a different backend origin; this public value
must never contain credentials.
